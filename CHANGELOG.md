# Changelog

## 0.1.0 — Initial experimental release

- Extract the local browser runner into an installable package.
- Configure URLs, expected video count, speed, runtime storage and optional OCR interpreter.
- Add bounded recovery, status-age reporting and single-instance locking.
- Provide a local two-video demo, browser tests and a GitHub Actions workflow.
- Require a current one-use approval before experimental local verification assistance.

Live-platform automatic CAPTCHA acceptance and general website support are not validated.
