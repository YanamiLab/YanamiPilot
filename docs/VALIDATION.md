## 本地 OCR 部署体积

2026-09-29 测量 ddddocr 1.6.1 安装文件：

| 文件 | 字节数 |
| --- | ---: |
| common.onnx | 54,088,400 |
| common_old.onnx | 13,606,051 |
| common_det.onnx | 20,127,694 |
| 合计 | 87,822,145 |

随包模型合计约 87.8 MB（83.8 MiB）。本机 macOS / ARM、Python 3.11 OCR 独立环境的磁盘占用约 324 MiB（340 MB），包括模型和依赖，浏览器单独安装；这是该环境的测量值，其他系统或依赖组合会有所变化。磁盘体积与运行内存是不同指标。

项目通过 ddddocr 默认 CPU 模式运行，本机安装源码的 `use_gpu` 默认值为 `False`，模型加载器使用 `CPUExecutionProvider`。识别模型随 ddddocr 安装包提供，识别子进程按需启动、完成后退出。
