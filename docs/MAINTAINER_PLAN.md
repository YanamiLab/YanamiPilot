# 首版之后的维护计划

目标是让新用户能复现、使用并贡献这个工具。

1. 发布首个实验版本，邀请实际用户执行本地 demo 和安装流程，记录环境与问题。
2. 优先修复可复现的安装、加载、重复页面与状态误判问题；每个修复关联具体 Issue 和回归测试。
3. 根据反馈形成下一版本范围，维护 CHANGELOG，定期发布实际可用的更新。
4. 提交开源支持计划申请时，如实列出自己的维护职责、真实用户反馈、代码变更、测试与发布记录。

[Codex for Open Source 官方说明](https://developers.openai.com/community/codex-for-oss)面向核心维护者及有使用价值的公开项目。获选需要官方审核。本项目没有预设获选结果，也不会把新仓库描述为已有广泛用户的成熟项目。
